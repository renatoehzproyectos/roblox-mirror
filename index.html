Arrastra tu archivo .rbxlx o .rbxl aquí o selecciona un archivo
Se parsea .rbxlx (XML) directamente en el navegador, sin subir nada a ningún servidor. Si sueltas un .rbxl (binario), Mirror no lo convierte por sí solo — el sandbox del navegador no puede ejecutar Termux — pero te da el comando exacto para convertirlo tú, con tu nombre de archivo ya insertado.
¿No tienes uno a mano?
.rbxl detectado — es binario, hace falta convertirlo a .rbxlx primero.
Convierte tu .rbxl en el servicio real desplegado (rbx_binary/rbx_xml) — arrastra el archivo abajo, descarga el .rbxlx resultante, y sueltalo en el dropzone de este Importer.
El convertidor corre en un servicio aparte (Railway) — nada de tu archivo pasa por Mirror ni por sus servidores.
  1. Si es la primera vez: pkg update -y && pkg upgrade -y, luego pkg install git golang -y, luego go install github.com/anaminus/rbxmk/rbxmk@latest y export PATH="$PATH:$HOME/go/bin".
  2. Da acceso a tus archivos: termux-setup-storage (acepta el permiso en Android).
  3. Copia tu archivo a la carpeta Download de tu celular si no está ahí.
  4. Pega y ejecuta el bloque de abajo completo en Termux.
  5. Cuando termine, arrastra el .rbxlx resultante aquí mismo, en este Importer.
Comando (cópialo tal cual a Termux)
El resultado puede pesar bastante más que el original — es normal, XML usa texto para representar lo que el binario guarda de forma compacta.
